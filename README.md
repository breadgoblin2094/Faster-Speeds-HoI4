# Faster-Speeds-HoI4
A mod that changes the speeds of the 5 buttons at the top right.

How to install it
1. Download and extract the ZIP.
2. Open Documents\Paradox Interactive\Hearts of Iron IV\mod.
3. Put the extracted FasterSpeeds folder and FasterSpeeds.mod file there.
4. Open the HOI4 launcher and enable Faster Speeds under Mods.
5. Launch the game and test it!
